# Phase 1 Baseline Implementation

This folder contains the baseline implementation used for Phase 1
of the DS340W project.

Original code source:

IBM - XGBoost + SMOTE Fraud Detection
https://github.com/IBM/xgboost-smote-detect-fraud

The code uses machine-learning techniques related to the parent paper,
including:

- XGBoost
- Handling imbalanced datasets
- SMOTE / sampling techniques
- Model evaluation
- Credit card fraud detection

The original code was executed and verified before any later
modifications were made.
