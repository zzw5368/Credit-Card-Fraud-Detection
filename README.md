# Credit Card Fraud Detection Using Machine Learning

## DS340W Project

This project investigates machine-learning techniques for detecting
fraudulent credit card transactions.

The primary approach is based on XGBoost with Bayesian optimization
and data-balancing techniques such as SMOTE and random undersampling.

## Parent Paper

Tayebi, M., & El Kafhali, S. (2025).
"A Novel Approach Based on XGBoost Classifier and Bayesian Optimization
for Credit Card Fraud Detection."

https://doi.org/10.1016/j.csa.2025.100093

## Dataset

Credit Card Fraud Detection Dataset:

https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud

## Project Goals

1. Explore and preprocess the credit card transaction dataset.
2. Examine the severe class imbalance between fraud and normal transactions.
3. Establish baseline machine-learning models.
4. Implement XGBoost for fraud detection.
5. Apply SMOTE and/or random undersampling.
6. Optimize XGBoost hyperparameters.
7. Compare model performance using appropriate evaluation metrics.
8. Compare our results with the parent paper.
