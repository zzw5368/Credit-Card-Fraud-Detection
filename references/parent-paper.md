# Parent Paper

Tayebi, M., & El Kafhali, S. (2025).
"A Novel Approach Based on XGBoost Classifier and Bayesian Optimization
for Credit Card Fraud Detection."

Journal: Cyber Security and Applications
Volume: 3
Article: 100093

DOI:
https://doi.org/10.1016/j.csa.2025.100093

Official publication:
https://www.sciencedirect.com/science/article/pii/S2772918425000104

## Techniques Used

- XGBoost
- Bayesian Optimization
- SMOTE
- Random Undersampling
- Classification model comparison

## Purpose

This paper serves as the parent paper for the DS340W Credit Card
Fraud Detection project. The project will attempt to reproduce and
evaluate techniques from the parent paper using an accessible
credit card fraud dataset.
